# TGAI GO 使用手册

> 面向第一次使用的朋友。**只要一个 `.TG` 文件 + 一行 pip install 就能跑推理。**

---

## 一、最快路径（3 步）

```bash
# 1. 装引擎（含原生库，不需要编译器）
pip install tgai-go

# 2. 拿一个 .TG 模型放到任意目录，例如 D:\models\v27.TG

# 3. 跑示例
python -c "
from tgai_go import TGEngine, ChatSession, generate
e = TGEngine(); e.load(r'D:\models\v27.TG')
s = ChatSession(e)
_, ids = s.build_prompt('你好')
print(''.join(generate(e, ids, {'max_tokens': 64}, s.eos, eos_set=s.eos_set)))
"
```

---

## 二、为什么只需要一个 `.TG`？

| 你需要准备的 | 说明 |
|---|---|
| ✅ **`.TG` 模型文件** | 唯一需要的东西 |
| ❌ 不需要 `tokenizer.json` | **分词器内嵌在 `.TG` 里**（词表 + BPE 合并规则）|
| ❌ 不需要编译 | 原生引擎（`libtgai_engine`）和 OpenMP 运行时**随 pip 包分发** |
| ❌ 不需要联网 | 完全离线推理 |
| ❌ 不需要 CUDA / Vulkan | CPU 即可（AVX2 加速）|

**`.TG` 里还内嵌了对话配置**：对话模板、停止符、采样默认值。所以换模型不用改代码 —— 引擎会读模型自己声明的配置。

## 四、API 速查

### 加载

```python
from tgai_go import TGEngine

e = TGEngine()                 # 也可 TGEngine(dll='自己的.dll')
e.load('model.TG')
# 可选参数：
#   extend_ctx=16384           扩展上下文（NTK 插值）
#   threads=4                  推理线程数
```

`e.cfg` 里有模型信息：`n_layers` / `d_model` / `vocab_size` / `max_seq` / `n_experts`。

### 对话

```python
from tgai_go import ChatSession

s = ChatSession(e)                       # 也可 ChatSession(e, sys_prompt='你是...')
prompt_text, ids = s.build_prompt('你好') # 拼出这一轮的 prompt
s.add('你好', answer_raw)                 # ★ 把回答写回历史
s.clear()                                # 清空历史 + 重置 KV cache
```

### 生成

```python
from tgai_go import generate

for tok in generate(e, ids, params, s.eos,
                    eos_set=s.eos_set,       # 停止符集合
                    kv=e.kv_handle()):       # ★ 传 kv ⇒ 多轮复用缓存
    print(tok, end='', flush=True)
```

**`generate()` 是生成器**，逐 token yield 文本 ⇒ 天然支持流式。

### 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `temperature` | 0.3 | 随机性；0 = 贪心 |
| `top_k` / `top_p` | 60 / 0.9 | 采样范围 |
| `max_tokens` | 2048 | 单次最多生成 |
| `min_tokens` | 1~4 | 最少生成（防立刻 EOS）|
| `repeat_penalty` | 1.05 | 重复惩罚 |
| `dry_multiplier` | 0.8 | DRY 防复读；0 = 关 |

**注意**：`.TG` 里声明的采样默认值不会被自动应用 —— 你传的 `params` 说了算。想知道模型推荐什么：

```python
from tgai_go import chat_meta_of
print(chat_meta_of('model.TG')['gen_defaults'])
```

## 五、性能

实测（Ryzen 7 7730U，8 核 16 线程，V2.7 3B MoE，BF16）：

| 线程数 | 生成速度 |
|---|---|
| 4 | ~11 tok/s |
| 8 | ~11 tok/s（**4 线程已饱和**）|
| 16 | ~10 tok/s（超线程反而略慢）|

**瓶颈是内存带宽，不是算力** —— 每生成一个 token 要把 1.7 GB 权重过一遍。所以：
- 线程数超过 4 基本没收益
- 想更快只能**降精度**（Q8_0 约 1.9×，Q4 约 3.6×）

首 token 延迟 ≈ `需算 token 数 × 50ms`。多轮对话会复用 KV cache，通常只需算新增的几十个 token。

## 六、⚠️ 必须知道的坑

### 1. 写回历史时不要 `strip()` 开头

```python
# ❌ 错：会破坏 KV cache 前缀，多轮越来越慢
s.add(q, ''.join(parts).strip())

# ✅ 对：只去尾部空白
from tgai_go import kv_safe_text
s.add(q, kv_safe_text(''.join(parts)))
```

**原因**：模型在 `<回答>` 标记后会自己先吐一个 `\n`，KV cache 里存的是带那个 `\n` 的序列。若 `strip()` 掉，下一轮拼出的 prompt 与 cache 前缀差 **1 个 token** ⇒ 最长公共前缀断裂 ⇒ **整段历史重算**。

实测代价：首 token 从 **1.9 秒恶化到 31.9 秒**。

### 2. 多轮对话必须传 `kv=`

```python
for tok in generate(e, ids, params, s.eos, eos_set=s.eos_set,
                    kv=e.kv_handle()):     # ★ 不传就每轮全量重算
```

### 3. 上下文别超过 `max_seq`

`e.max_seq` 是模型上限（V2.7 是 8192）。prompt + 生成长度超了会失败。长对话要自己截断历史，或启动时 `extend_ctx=` 扩上下文。

## 七、换模型

```python
e.free()                     # 释放旧模型（KV + 权重 + 线程池）
e2 = TGEngine()
e2.load('另一个.TG')
s = ChatSession(e2)          # 建新会话（历史清空）
```

`.TG` 里内嵌了对话模板和停止符，所以**换不同版本/不同架构的 TGAI 模型都不用改代码**。

## 八、常见问题

**Q: 报 `ImportError: DLL load failed`？**
缺 MSVC 运行库。装 [VC++ 2015-2022 x64 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

**Q: 输出里有 `<UNK>`？**
模型训练语料里出现过词表外字符，属模型侧问题，不是引擎 bug。

**Q: 输出里有很多 `▁`？**
你用的是旧版。1.0.1 起已修（SentencePiece detokenize）。`pip install -U tgai-go`。

**Q: 生成很慢 / 首 token 等很久？**
先看是不是第 6 节的坑 1（`strip()` 破坏缓存）。在 TUI 里每轮会显示 `[停止原因 · prefill N]`，`prefill` 接近 prompt 全长就说明缓存没命中。

**Q: 怎么知道模型有哪些可用配置？**
```python
from tgai_go import chat_meta_of
m = chat_meta_of('model.TG')
print(m.get('stop_strings'))    # 停止符
print(m.get('gen_defaults'))    # 推荐采样参数
print(m.get('chat_template'))   # 对话模板
```

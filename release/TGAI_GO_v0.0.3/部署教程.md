| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| 开发板 | ESP32-S3 N16R8 | ESP32-S3 N16R8 |
| PSRAM | 8 MB | 8 MB 以上 |
| Flash | 16 MB | 16 MB |
| 模型格式 | .TG (Q4_0) | .TG (Q4_0) |

## 2. 部署（两种方式任选一种）

### 方式一：一键部署（推荐）

1. 解压 `TGAI_GO_v0.0.3.zip`
2. 双击运行 `setup.bat`
3. 自动完成以下步骤：
   - 安装 Python 依赖（PyQt6, pyserial, esptool）
   - 安装 Arduino 库到 `文档\Arduino\libraries\`
   - 安装 Mixly 积木库到 ThirdParty
   - 安装 Arduino 库到 Mixly 的 myLib（编译固件时需要）

### 方式二：手动部署

共需复制到 **三个位置**：

**位置1 — Mixly 积木库（ThirdParty）：**
```
Mixly_library\TGAI_GO  →  {Mixly}\resources\app\src\boards\default\arduino_esp32s3\libraries\ThirdParty\TGAI_GO
```

**位置2 — Arduino 库（myLib，编译固件用）：**
```
Arduino_library\TGAI_GO  →  {Mixly}\resources\app\src\boards\default\arduino_esp32s3\libraries\myLib\TGAI_GO
```

**位置3 — Arduino 库（全局）：**
```
Arduino_library\TGAI_GO  →  {用户}\Documents\Arduino\libraries\TGAI_GO
```

> 例如 Mixly 在 `D:\mixly2.0-win32-x64`：
> ```
> 复制 Mixly_library\TGAI_GO → D:\mixly2.0-win32-x64\resources\app\src\boards\default\arduino_esp32s3\libraries\ThirdParty\TGAI_GO
> 复制 Arduino_library\TGAI_GO → D:\mixly2.0-win32-x64\resources\app\src\boards\default\arduino_esp32s3\libraries\myLib\TGAI_GO
> ```

> **提示**：上传工具需要 Python + PyQt6。如果没装，运行 `tools\upload_model.bat` 会自动检测并安装。

## 3. Mixly 固件配置（重要！）

打开 Mixly，**选择开发板 "ESP32S3 Dev Module"**，然后按以下配置：

| 配置项 | 设置值 | 说明 |
|--------|--------|------|
| **PSRAM** | **OPI PSRAM** | 必须开启，否则无法分配KV缓存 |
| **Flash Mode** | QIO 80MHz | |
| **Flash Size** | **16MB (128Mb)** | N16R8的Flash大小 |
| **Partition Scheme** | Default 4MB with spiffs (1.2MB APP/1.5MB SPIFFS) | 模型通过上传工具写入SPIFFS分区 |
| **Arduino Runs On** | Core 1 | |
| **Events Run On** | Core 1 | |
| **USB Mode** | USB-OTG (TinyUSB) | |
| **USB CDC On Boot** | Disabled | |
| **USB Firmware MSC On Boot** | Disabled | |
| **USB DFU On Boot** | Disabled | |
| **Upload Mode** | UART0 / Hardware CDC | |
| **CPU Frequency** | 240MHz (WiFi) | |
| **Upload Speed** | 921600 | |

> **注意**：PSRAM 必须设为 OPI PSRAM，Flash Size 必须设为 16MB，否则无法运行！

## 4. 上传模型到 ESP32

### 方式一：使用上传工具（推荐）

1. 双击 `tools\upload_model.bat` 启动上传工具
2. 工具界面说明：
   - **工具检测**：启动时自动检查同目录的 `mklittlefs.exe` 和 `esptool.exe`，显示 ✓/✗。如果两个工具都在，无需额外配置
   - **串口**：选择 ESP32 对应的 COM 口
   - **波特率**：921600
   - **开发板**：ESP32-S3
   - **分区方案**：ESP32-S3 16MB (N16R8)（偏移 0x310000）
   - **模型文件**：点击选择 .TG 模型
3. 点击"开始上传"，等待完成

> **注意**：工具已自带 `mklittlefs.exe` 和 `esptool.exe`。只有自带工具缺失时才需指定 Mixly 安装目录。

### 方式二：命令行

```bash
# 1. 生成 LittleFS 镜像
mklittlefs -c ./model_folder -b 4096 -p 256 -s 0xCF0000 littlefs.bin

# 2. 烧录
esptool.exe --chip esp32s3 --port COM5 --baud 921600 write_flash 0x310000 littlefs.bin
```

## 7. 常见问题

### Q: PSRAM 显示"可用: 116 KB"怎么办？
A: PSRAM 未开启或不是 OPI 模式。检查 Mixly 固件配置中 PSRAM 是否设为"OPI PSRAM"。

### Q: 编译报错 "TGAI_GO.h not found"？
A: Arduino 库未安装。两种方式：
  - 运行 `setup.bat` 自动安装
  - 手动：把 `Arduino_library\TGAI_GO` 复制到 `文档\Arduino\libraries\` 和 Mixly 的 `myLib\` 目录

### Q: 积木栏找不到 TGAI GO？
A: 重启 Mixly。如仍无，检查 Mixly 库路径是否正确复制到 ThirdParty 目录。

### Q: 上传模型时提示"esptool ✗"但文件存在？
A: 确认 `tools\esptool_py\` 下有 `esptool.exe`（PyInstaller 打包版）或 `esptool.py`。工具同时检查两种格式。

### Q: 模型回复乱码？
A: 
1. 确认模型的 vocab 是 UTF-8 中文
2. 温度设太高（建议 0.6~0.8）
3. 使用 Q4_0 量化的模型

### Q: 上传模型后 ESP32 不断重启？
A: 可能原因：
1. PSRAM 不足 — 确认 PSRAM=OPI、Flash=16MB，使用 Q4_0 模型
2. 库版本过旧 — 确保 Arduino 库已更新到 v0.0.3（修复了堆腐败bug）

### Q: 支持哪些 ESP32 系列？
A: 必须带 PSRAM：ESP32-S3（推荐）、ESP32 WROVER、ESP32-S2 带PSRAM版。ESP32-C3/C6/ESP8266 不支持（无PSRAM）。

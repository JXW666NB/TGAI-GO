```

   （命令行引号完全正确，仍失败）
   ⇒ 解法：用 junction 建无空格 ASCII 路径
     mklink /J D:\tgai_build\mxlib "<含空格中文的路径>"

② PowerShell here-string 里 "$mx\..." 会把 \ 后的字符当变量名一部分
   ⇒ 解法：改用 "${mx}\..."

   ⇒ 已补（旧示例用到）
```
